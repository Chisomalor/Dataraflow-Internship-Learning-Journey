# Week 2 — Object-Oriented Programming

## Overview

Week 2 focused on Object-Oriented Programming (OOP) and a different way of organising Python programs.

I started thinking beyond individual functions and variables and began working with objects, attributes and behaviours.

## Topics Covered

- Classes and objects
- Constructors
- Attributes and methods
- Encapsulation and scope
- Inheritance
- Polymorphism
- Iterators
- Data structures and algorithms

## Main Project

### Library Management System

My Week 2 project was a Library Management System designed to apply the OOP concepts covered during the week.

The project helped me connect concepts such as inheritance, polymorphism, encapsulation and iterators in one practical program.
